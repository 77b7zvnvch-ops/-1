# Alley Messenger · 街巷来信

浏览器运行的第三人称街巷漫游原型。无需安装 Windows 程序或本地 Node.js。

## 操作
- W A S D：移动
- 鼠标拖动：环视
- 手机屏幕：方向按钮

## 美术来源
当前首版场景由本仓库原创程序化几何与 Canvas 表面细节组成，没有复制 messenger.abeto.co 或其他游戏的专有模型、贴图或音乐。目标是逐步靠近日系手绘城市巷道：旧式外墙、店铺雨棚、楼梯、电线、杂物和第三人称角色。它是原创风格化近似，不宣称 1:1 复刻。

## 运行依赖
Three.js 通过 jsDelivr 加载，项目地址：https://github.com/mrdoob/three.js （MIT）。

## 发布
推送到 main 后由 GitHub Actions 发布 GitHub Pages。若首次发布未启动，请到 Settings → Pages → Build and deployment 选择 GitHub Actions。
